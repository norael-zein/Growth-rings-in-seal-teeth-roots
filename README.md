# Seal Age Estimation (GLG Tool)

This repository contains an application for estimating the age of seals based on growth layer groups (GLGs) in tooth images.

---

## Step 1: Install Python

1. Go to: https://www.python.org/downloads/
2. Download Python 3.11

### Verify Python works
Open a terminal and perform the following: 

#### Windows:
- Press Win + R
- Type cmd
- Press Enter

#### macOS / Linux:
- Open Terminal

Run: _python --version_

You should see something like: _Python 3.11.x_

---

## Step 2: Download this repository

1. On GitHub, click the green Code button
2. Click Download ZIP
3. Unzip the downloaded folder and add it to your desktop
4. Open the folder in a program where you can run the code (for example Visual Studio Code)
---

## Step 3: Install required packages

**Run**:
_pip install -r requirements.txt_
## Step 4: Run the application

**Run**:
_python ui-4.0.py_

When the application starts, it will display a message indicating that it is running locally.

---

## Step 5: Open the application in your browser

Copy the address shown in the terminal and paste it into your web browser. It should look something like: _http://127.0.0.1:XXXX_
